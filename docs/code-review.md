# Код-ревью

Дата аудита: 26 июля 2026.

## Исправлено

- Критическое повышение привилегий: публичная регистрация больше не принимает роль тренера/куратора.
- Критический обход SMS-аутентификации: удалены endpoints с постоянным кодом `1111`.
- Пароли: Argon2id, минимум 12 символов для клиентов и 16 для первичных staff-секретов.
- Персональные контакты: email и телефон шифруются Laravel Crypt; поиск и уникальность работают по HMAC blind indexes.
- Заблокированные и архивные пользователи больше не могут войти.
- Web-токены ограничены 8 часами, прежние токены при входе отзываются, frontend хранит токен только в `sessionStorage`.
- Добавлен rate limit на вход и регистрацию, CORS allowlist, HTTPS/security headers и запрет публикации runtime-файлов.
- Пользовательские загрузки перенесены из `public/uploads` в Timeweb S3; платное видео выдаётся через CDN Secure Token.
- Удалены тестовые seed-данные, тестовые логины из README, загруженные тестовые файлы и runtime-лог.
- Добавлены отдельные production images, непривилегированные PHP-процессы, opcache, healthchecks, queue и scheduler.

## Важные ограничения перед запуском

- Email администратора и куратора должны различаться. Указанный `lazareva.secret@yandex.ru` закреплён за Анастасией; `CURATOR_EMAIL` должен предоставить владелец.
- `PAYMENT_PROVIDER=mock` нельзя использовать в production. До приёма денег нужно подключить реального провайдера и проверку подписи webhook.
- LiveKit/Coturn production-секреты и сетевые правила нужно задать отдельно; dev-значения запрещены.
- Frontend пока написан на JavaScript, хотя целевая архитектура требует TypeScript. Это технический долг, а не блокер безопасного деплоя.
- Для чувствительных медицинских данных необходимы организационные меры: матрица доступа, журналирование просмотров, сроки хранения/удаления, договоры с обработчиками и юридическая проверка по применимому законодательству.
